---
title: 'Get All Wallet Transactions'
openapi: 'GET /api/v1/wallets/crypto/{walletId}/transactions'
description: 'Retrieve all transactions for a crypto wallet'
---

## Path Parameters

<ParamField path="walletId" type="string" required>
  Crypto wallet ID (crypto address entity ID)
</ParamField>

## Headers

<ParamField header="x-api-key" type="string" required>
  API Key for authentication
</ParamField>

## Query Parameters

<ParamField query="page" type="number" default="1">
  Page number for pagination
</ParamField>

<ParamField query="limit" type="number" default="10">
  Number of items per page
</ParamField>

<ParamField query="transactionType" type="string">
  Filter by the lowercase transaction values supported by the API, such as `deposit` or `withdrawal`.
</ParamField>

<ParamField query="startDate" type="string">
  Start date filter (ISO string)
</ParamField>

<ParamField query="endDate" type="string">
  End date filter (ISO string)
</ParamField>

## Request Example

```bash
curl -X GET "https://api-production.fossapay.com/api/v1/wallets/crypto/55555555-5555-4555-8555-555555555555/transactions?page=1&limit=10&transactionType=deposit" \
  -H "x-api-key: $FOSSAPAY_API_KEY"
```

```javascript
const url = new URL(
  'https://api-production.fossapay.com/api/v1/wallets/crypto/55555555-5555-4555-8555-555555555555/transactions'
);

url.searchParams.set('page', '1');
url.searchParams.set('limit', '10');
url.searchParams.set('transactionType', 'deposit');
url.searchParams.set('startDate', '2024-01-01T00:00:00Z');
url.searchParams.set('endDate', '2024-12-31T23:59:59Z');

const response = await fetch(url.toString(), {
  method: 'GET',
  headers: {
    'x-api-key': process.env.FOSSAPAY_API_KEY,
  },
});

if (!response.ok) {
  throw new Error(`Request failed: ${response.status} ${response.statusText}`);
}

const data = await response.json();
const transactions = data.data.transactions;
console.log(transactions);
```

## Error Responses

<ErrorResponse code="400">
```json Bad Request
{
  "status": "error",
  "statusCode": 400,
  "message": "Wallet not found"
}
```
</ErrorResponse>

Missing and non-owned crypto wallets currently return HTTP `400`; invalid query fields return `422`; authentication failures return `401`.
