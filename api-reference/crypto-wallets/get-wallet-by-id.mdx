---
title: 'Get Wallet by ID'
openapi: '/api-reference/openapi.json GET /api/v1/wallets/crypto/{walletId}'
description: 'Retrieve crypto wallet details by wallet ID'
---

## Path Parameters

<ParamField path="walletId" type="string" required>
  FossaPay crypto-address entity UUID. This is not the provider `walletId` returned by wallet creation.
</ParamField>

## Headers

<ParamField header="x-api-key" type="string" required>
  Active production API key. The wallet must belong to the authenticated merchant.
</ParamField>

## Request Example

```bash
curl -X GET https://api-production.fossapay.com/api/v1/wallets/crypto/55555555-5555-4555-8555-555555555555 \
  -H "x-api-key: $FOSSAPAY_API_KEY"
```

```javascript
const response = await fetch(
  'https://api-production.fossapay.com/api/v1/wallets/crypto/55555555-5555-4555-8555-555555555555',
  {
    method: 'GET',
    headers: {
      'x-api-key': process.env.FOSSAPAY_API_KEY
    }
  }
);

if (!response.ok) {
  throw new Error(`Request failed: ${response.status} ${response.statusText}`);
}

const wallet = await response.json();
```

## Error Responses

<ErrorResponse code="400">
```json Bad Request
{
  "status": "error",
  "statusCode": 400,
  "message": "Wallet not found"
}
```
</ErrorResponse>

The current service reports missing and non-owned crypto wallets as HTTP `400`; authentication failures return `401`.
