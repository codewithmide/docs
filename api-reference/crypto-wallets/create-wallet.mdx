---
title: 'Create Crypto Wallet'
openapi: '/api-reference/openapi.json POST /api/v1/wallets/crypto/create'
description: 'Create a Solana or Stellar wallet for a merchant-owned customer'
---

## Request

<ParamField header="x-api-key" type="string" required>
  Active production API key belonging to the customer's merchant.
</ParamField>

<ParamField body="network" type="string" required>
  The blockchain network for the crypto wallet: `solana` or `stellar`.
</ParamField>

<ParamField body="customerId" type="string" required>
  FossaPay customer UUID. One wallet per network can be created for this customer.
</ParamField>

### Request Example

```bash
curl -X POST https://api-production.fossapay.com/api/v1/wallets/crypto/create \
  -H "x-api-key: $FOSSAPAY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "network": "stellar",
    "customerId": "11111111-1111-4111-8111-111111111111"
  }'
```

```javascript
const response = await fetch('https://api-production.fossapay.com/api/v1/wallets/crypto/create', {
  method: 'POST',
  headers: {
    'x-api-key': process.env.FOSSAPAY_API_KEY,
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    network: 'stellar',
    customerId: '11111111-1111-4111-8111-111111111111'
  })
});

if (!response.ok) {
  throw new Error(`Request failed: ${response.status} ${response.statusText}`);
}

const cryptoWallet = await response.json();
```

## Response

<ResponseExample>
```json Success Response
{
  "status": "success",
  "statusCode": 201,
  "message": "Crypto wallet created successfully",
  "data": {
    "id": "55555555-5555-4555-8555-555555555555",
    "walletId": "wallet-reference-123",
    "address": "GAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAWHF",
    "network": "stellar"
  }
}
```
</ResponseExample>

Use `data.id` for wallet-by-ID and wallet-transactions endpoints. Use `data.address` for wallet-by-address requests. Save the network and full address with the customer ID. The example address is illustrative; use the address in your actual response.

## Errors

| Status | Typical cause |
|---|---|
| `400` | Customer not found, wallet already exists, or wallet creation failed |
| `401` | Missing or invalid API key |
| `422` | Invalid customer UUID or a `network` other than `solana` or `stellar` |
| `5xx` | Temporary service failure; check for an existing wallet before retrying |
