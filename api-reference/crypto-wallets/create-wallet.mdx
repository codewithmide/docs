---
title: 'Create Crypto Wallet'
openapi: '/api-reference/openapi.json POST /api/v1/wallets/crypto/create'
description: 'Create the Solana stablecoin wallet for a merchant-owned customer'
---

## Request

<ParamField header="x-api-key" type="string" required>
  Active production API key belonging to the customer's merchant.
</ParamField>

<ParamField body="network" type="string" required>
  The blockchain network for the crypto wallet. The only supported value is `solana`.
</ParamField>

<ParamField body="customerId" type="string" required>
  FossaPay customer UUID. Only one Solana wallet can be created for the customer.
</ParamField>

### Request Example

```bash
curl -X POST https://api-production.fossapay.com/api/v1/wallets/crypto/create \
  -H "x-api-key: $FOSSAPAY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "network": "solana",
    "customerId": "11111111-1111-4111-8111-111111111111"
  }'
```

```javascript
const response = await fetch('https://api-production.fossapay.com/api/v1/wallets/crypto/create', {
  method: 'POST',
  headers: {
    'x-api-key': process.env.FOSSAPAY_API_KEY,
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    network: 'solana',
    customerId: '11111111-1111-4111-8111-111111111111'
  })
});

if (!response.ok) {
  throw new Error(`Request failed: ${response.status} ${response.statusText}`);
}

const cryptoWallet = await response.json();
```

## Response

<ResponseExample>
```json Success Response
{
  "status": "success",
  "statusCode": 201,
  "message": "Crypto wallet created successfully",
  "data": {
    "walletId": "user:u3d",
    "address": "So11111111111111111111111111111111111111112",
    "network": "solana"
  }
}
```
</ResponseExample>

`walletId` in this creation response is the provider wallet identifier. Persist it together with the complete Solana address and customer UUID. Use address lookup when reconciling the newly created wallet unless you have the FossaPay crypto-address entity UUID required by the ID lookup endpoint.

## Errors

| Status | Typical cause |
|---|---|
| `400` | Customer not found, wallet already exists, or provider wallet creation failed |
| `401` | Missing or invalid API key |
| `422` | Invalid customer UUID or a `network` other than `solana` |
| `5xx` | Temporary platform or provider failure; reconcile before retrying |
