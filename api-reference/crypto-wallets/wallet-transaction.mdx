---
title: 'Get Wallet Single Transaction'
openapi: 'GET /api/v1/wallets/crypto/transactions/{transactionId}'
description: 'Retrieve a single crypto wallet transaction by transaction ID'
---

## Path Parameters

<ParamField path="transactionId" type="string" required>
  Transaction ID
</ParamField>

## Headers

<ParamField header="x-api-key" type="string" required>
  API Key for authentication
</ParamField>

## Request Example

```bash
curl -X GET https://api-production.fossapay.com/api/v1/wallets/crypto/transactions/44444444-4444-4444-8444-444444444401 \
  -H "x-api-key: $FOSSAPAY_API_KEY"
```

```javascript
const response = await fetch(
  'https://api-production.fossapay.com/api/v1/wallets/crypto/transactions/44444444-4444-4444-8444-444444444401',
  {
    method: 'GET',
    headers: {
      'x-api-key': process.env.FOSSAPAY_API_KEY
    }
  }
);

if (!response.ok) {
  throw new Error(`Request failed: ${response.status} ${response.statusText}`);
}

const transaction = await response.json();
```

## Error Responses

```json Bad Request

  "statusCode": 400,

}
```
</ErrorResponse>

Missing and non-owned crypto transactions currently return HTTP `400`; authentication failures return `401`.
