---
title: "Get Customer by ID"
openapi: "GET /api/v1/customers/{customerId}"
description: "Retrieve a merchant-owned customer by UUID"
---

## Overview

Retrieve detailed information about a specific customer using their unique customer ID.

## Request

<ParamField header="x-api-key" type="string" required>
  Your API key for authentication
</ParamField>

<ParamField path="customerId" type="string" required>
  FossaPay customer UUID. The customer must belong to the authenticated merchant.
</ParamField>

## Response

<ResponseField name="status" type="string">
  Response status: `success` or `error`
</ResponseField>

<ResponseField name="statusCode" type="number">
  HTTP status code (200 for successful retrieval)
</ResponseField>

<ResponseField name="message" type="string">
  Human-readable response message
</ResponseField>

<ResponseField name="data" type="object">
  Customer object
</ResponseField>

## Example

<Tabs>
<Tab title="cURL">

```bash
curl -X GET https://api-production.fossapay.com/api/v1/customers/11111111-1111-4111-8111-111111111111 \
  -H "x-api-key: $FOSSAPAY_API_KEY"
```

</Tab>
<Tab title="Node.js">

```javascript
const customerId = "11111111-1111-4111-8111-111111111111";
const response = await fetch(
  `https://api-production.fossapay.com/api/v1/customers/${customerId}`,
  {
    method: "GET",
    headers: {
      "x-api-key": process.env.FOSSAPAY_API_KEY,
    },
  },
);

const customer = await response.json();
if (!response.ok) throw new Error(customer.message);
```

</Tab>
</Tabs>

## Errors

| Status | Typical cause |
|---|---|
| `401` | Missing or invalid API key |
| `404` | Customer UUID was not found for the authenticated merchant |

<Note>
  Customer access is merchant-scoped. Persist the returned customer UUID with your own user identifier.
</Note>
