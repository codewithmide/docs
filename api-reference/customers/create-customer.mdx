---
title: 'Create Customer Account'
openapi: 'POST /api/v1/customers'
description: 'Create an individual customer owned by the authenticated merchant'
---

## Request

<ParamField header="x-api-key" type="string" required>
  Active production API key belonging to the merchant that will own the customer.
</ParamField>

<ParamField body="firstName" type="string" required>
  Exactly one given name. Spaces and numbers are not accepted.
</ParamField>

<ParamField body="lastName" type="string" required>
  Exactly one family name. Spaces and numbers are not accepted.
</ParamField>

<ParamField body="middleName" type="string">
  Optional single middle name. Do not combine multiple names in this field.
</ParamField>

<ParamField body="emailAddress" type="string" required>
  Non-empty email address. It must be unique within the authenticated merchant.
</ParamField>

<ParamField body="mobileNumber" type="string" required>
  Non-empty mobile number retained by FossaPay.
</ParamField>

<ParamField body="dateOfBirth" type="string" required>
  Date of birth in YYYY-MM-DD format (e.g., 1990-08-15)
</ParamField>

<ParamField body="address" type="string" required>
  Address of the customer
</ParamField>

<ParamField body="city" type="string" required>
  City of the customer
</ParamField>

<ParamField body="country" type="string" required>
  Country of the customer
</ParamField>

<ParamField body="type" type="string" required>
  Customer account type. The only accepted value is `individual`; other values return HTTP `422` before provider processing.
</ParamField>

### Request Example

```bash
curl -X POST https://api-production.fossapay.com/api/v1/customers \
  -H "x-api-key: $FOSSAPAY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "firstName": "John",
    "lastName": "Doe",
    "middleName": "Michael",
    "emailAddress": "john.doe@example.com",
    "mobileNumber": "+2348012345678",
    "dateOfBirth": "1990-08-15",
    "address": "123 Example Street",
    "city": "Lagos",
    "country": "Nigeria",
    "type": "individual"
  }'
```

```python
import requests

headers = {
    'x-api-key': process.env.FOSSAPAY_API_KEY,
    'Content-Type': 'application/json'
}

data = {
    'firstName': 'John',
    'lastName': 'Doe',
    'middleName': 'Michael',
    'emailAddress': 'john.doe@example.com',
    'mobileNumber': '+2348012345678',
    'dateOfBirth': '1990-08-15',
    'address': '123 Example Street',
    'city': 'Lagos',
    'country': 'Nigeria',
    'type': 'individual'
}

response = requests.post('https://api-production.fossapay.com/api/v1/customers', headers=headers, json=data)
customer = response.json()
response.raise_for_status()
```

## Errors

| Status | Typical cause |
|---|---|
| `400` | Duplicate email, unsupported country, or downstream customer-creation rejection |
| `401` | Missing or invalid API key |
| `422` | Missing or unknown field, invalid name, invalid date format, or `type` other than `individual` |
| `5xx` | Temporary FossaPay or provider failure; reconcile before retrying |

<Tip>
  Store `data.id` in your database. Customer wallet and transfer operations require this UUID.
</Tip>
