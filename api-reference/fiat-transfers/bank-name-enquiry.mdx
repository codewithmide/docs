---
title: 'Bank Name Enquiry'
openapi: '/api-reference/openapi.json POST /api/v1/transfers/fiat/bank-name-enquiry'
description: 'Resolve an account name before submitting an NGN transfer'
---

## Request

<ParamField header="x-api-key" type="string" required>
  Active production API key.
</ParamField>

<ParamField body="bankCode" type="string" required>
  Bank code returned by the supported-banks endpoint.
</ParamField>

<ParamField body="accountNumber" type="string" required>
  Destination account number to resolve.
</ParamField>

### Request Example

```bash
curl -X POST https://api-production.fossapay.com/api/v1/transfers/fiat/bank-name-enquiry \
  -H "x-api-key: $FOSSAPAY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "bankCode": "044",
    "accountNumber": "0123456789"
  }'
```

```javascript
const response = await fetch('https://api-production.fossapay.com/api/v1/transfers/fiat/bank-name-enquiry', {
  method: 'POST',
  headers: {
    'x-api-key': process.env.FOSSAPAY_API_KEY,
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    bankCode: '044',
    accountNumber: '0123456789'
  })
});

if (!response.ok) {
  throw new Error(`Request failed: ${response.status} ${response.statusText}`);
}

const enquiry = await response.json();
```

<Warning>
  A successful enquiry does not guarantee a later transfer. Confirm that the returned account name matches the intended beneficiary before proceeding.
</Warning>

## Errors

| Status | Typical cause |
|---|---|
| `400` | Provider rejected the bank code or account details |
| `401` | Missing or invalid API key |
| `422` | Missing or invalid request field |
| `503` | Name-enquiry provider temporarily unavailable |
