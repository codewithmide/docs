---
title: 'Get Supported Banks'
openapi: '/api-reference/openapi.json GET /api/v1/transfers/fiat/banks'
description: 'Retrieve the current Nigerian banks and codes supported for NGN transfers'
---

## Request

<ParamField header="x-api-key" type="string" required>
  Active production API key.
</ParamField>

### Request Example

```bash
curl -X GET https://api-production.fossapay.com/api/v1/transfers/fiat/banks \
  -H "x-api-key: $FOSSAPAY_API_KEY"
```

```javascript
const response = await fetch('https://api-production.fossapay.com/api/v1/transfers/fiat/banks', {
  method: 'GET',
  headers: {
    'x-api-key': process.env.FOSSAPAY_API_KEY
  }
});

if (!response.ok) {
  throw new Error(`Request failed: ${response.status} ${response.statusText}`);
}

const banks = await response.json();
if (!response.ok) throw new Error(banks.message);
```

## Errors

| Status | Typical cause |
|---|---|
| `400` | Operation or provider request is unavailable |
| `401` | Missing or invalid API key |
| `5xx` | Temporary FossaPay or provider failure |
