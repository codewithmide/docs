---
title: 'Inter-Bank Transfer (External Bank)'
openapi: '/api-reference/openapi.json POST /api/v1/transfers/fiat/inter-bank'
description: 'Send NGN from FossaPay to an account at another supported Nigerian bank'
---

Send NGN to a recipient whose account is at a bank outside the bank used for FossaPay NGN wallets.

<Info>
  Use inter-bank transfer for external bank accounts. First confirm the destination bank is supported, perform a bank name enquiry, and calculate the applicable transfer fee.
</Info>

<Tip>
  If both people are FossaPay customers under the same business, use the [free Wallet-to-Wallet Transfer endpoint](/api-reference/virtual-account/wallet-transfer) instead.
</Tip>

## Request

<ParamField header="x-api-key" type="string" required>
  Active production API key belonging to the customer and source wallet merchant.
</ParamField>

<ParamField body="customerId" type="string" required>
  UUID of the customer initiating the transfer
</ParamField>

<ParamField body="destinationBankCode" type="string" required>
  The bank code of the external destination bank
</ParamField>

<ParamField body="destinationAccountName" type="string" required>
  The name of the destination account holder
</ParamField>

<ParamField body="destinationAccountNumber" type="string" required>
  The recipient's account number at the external destination bank
</ParamField>

<ParamField body="destinationBankName" type="string" required>
  The name of the external destination bank
</ParamField>

<ParamField body="reference" type="string" required>
  Unique logical transfer reference generated and persisted by your system. Maximum 36 characters. Use a concise, provider-safe value; requests with a longer reference are rejected before any funds move.
</ParamField>

<ParamField body="remarks" type="string" required>
  Additional remarks or description for the transfer
</ParamField>

<ParamField body="amount" type="number" required>
  Amount delivered to the beneficiary. The customer wallet is debited this amount plus the configured fee.
</ParamField>

### Request Example

```bash
curl -X POST https://api-production.fossapay.com/api/v1/transfers/fiat/inter-bank \
  -H "x-api-key: $FOSSAPAY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "customerId": "11111111-1111-4111-8111-111111111111",
    "destinationBankCode": "044",
    "destinationAccountName": "JOHN DOE",
    "destinationAccountNumber": "1234567890",
    "destinationBankName": "ACCESS BANK",
    "reference": "TRF-2026-10025",
    "remarks": "Customer withdrawal",
    "amount": 50000.00
  }'
```

```javascript
const response = await fetch('https://api-production.fossapay.com/api/v1/transfers/fiat/inter-bank', {
  method: 'POST',
  headers: {
    'x-api-key': process.env.FOSSAPAY_API_KEY,
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    customerId: '11111111-1111-4111-8111-111111111111',
    destinationBankCode: '044',
    destinationAccountName: 'JOHN DOE',
    destinationAccountNumber: '1234567890',
    destinationBankName: 'ACCESS BANK',
    reference: 'TRF-2026-10025',
    remarks: 'Customer withdrawal',
    amount: 50000.00
  })
});

const data = await response.json();
```

The request `reference` is the replay and reconciliation identifier. It must be 36 characters or fewer. This endpoint does not use `X-Idempotency-Key`. After a timeout, reconcile by reference and wallet history before creating another transfer.

## Errors

| Status | Typical cause |
|---|---|
| `400` | Customer/wallet missing, insufficient funds, duplicate processing, provider failure, or unresolved outcome |
| `401` | Missing or invalid API key |
| `404` | Customer wallet balance or related resource not found |
| `422` | Missing or invalid request field, including a `reference` longer than 36 characters |
| `5xx` | Temporary platform or provider failure; reconcile before retrying |
