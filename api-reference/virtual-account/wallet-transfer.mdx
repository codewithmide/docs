---
title: 'Wallet-to-Wallet Transfer (Free)'
openapi: '/api-reference/openapi.json POST /api/v1/wallets/fiat/transfers/wallet-to-wallet'
description: 'Transfer NGN for free between two customers under the same business'
---

Move funds instantly between two FossaPay NGN wallets belonging to customers under your business. Wallet-to-wallet transfers are free.

<Info>
  Use this endpoint only when both the sender and recipient are FossaPay customers created under the same business and both account numbers belong to their FossaPay NGN wallets.
</Info>

<Warning>
  To send money to an account at another bank, use the [Inter-Bank Transfer endpoint](/api-reference/fiat-transfers/inter-bank-transfer) instead.
</Warning>

## Request

<ParamField header="x-api-key" type="string" required>
  API Key for authentication
</ParamField>

<ParamField body="fromAccount" type="string" required>
  FossaPay NGN wallet account number belonging to the sending customer
</ParamField>

<ParamField body="toAccount" type="string" required>
  FossaPay NGN wallet account number belonging to another customer under the same business
</ParamField>

<ParamField body="amount" type="number" required>
  Transfer amount
</ParamField>

<ParamField body="reference" type="string" required>
  A unique transfer reference. Do not reuse a reference from a failed, reversed, cancelled, or otherwise completed transfer.
</ParamField>

<ParamField body="narration" type="string" required>
  A non-empty transfer narration or description, up to 255 characters. It may match your reference, but it does not need to.
</ParamField>

### Request Example

```bash
curl -X POST https://api-production.fossapay.com/api/v1/wallets/fiat/transfers/wallet-to-wallet \
  -H "x-api-key: $FOSSAPAY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "fromAccount": "1234567890",
    "toAccount": "0987654321",
    "amount": 5000,
    "reference": "transfer_ref_001",
    "narration": "Payment for services"
  }'
```

```javascript
const response = await fetch('https://api-production.fossapay.com/api/v1/wallets/fiat/transfers/wallet-to-wallet', {
  method: 'POST',
  headers: {
    'x-api-key': process.env.FOSSAPAY_API_KEY,
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    fromAccount: '1234567890',
    toAccount: '0987654321',
    amount: 5000,
    reference: 'transfer_ref_001',
    narration: 'Payment for services'
  })
});

const data = await response.json();
```

```python
import os
import requests

url = "https://api-production.fossapay.com/api/v1/wallets/fiat/transfers/wallet-to-wallet"
headers = {
    "x-api-key": os.environ["FOSSAPAY_API_KEY"],
    "Content-Type": "application/json"
}
data = {
    "fromAccount": "1234567890",
    "toAccount": "0987654321",
    "amount": 5000,
    "reference": "transfer_ref_001",
    "narration": "Payment for services"
}

response = requests.post(url, headers=headers, json=data)
data = response.json()
```

## Response

No transfer fee is charged for a successful wallet-to-wallet transfer.

<ResponseField name="status" type="string">
  `success` when the synchronous wallet transfer completes.
</ResponseField>

<ResponseField name="statusCode" type="number">
  HTTP status code. Successful submission currently returns `201`.
</ResponseField>

<ResponseField name="message" type="string">
  Human-readable response message
</ResponseField>

### Response Example

<ResponseExample>
```json Success Response
{
  "status": "success",
  "statusCode": 201,
  "message": "Wallet transfer successfull"
}
```

```json Error Response
{
  "status": "error",
  "statusCode": 403,
  "message": "The destination wallet you are trying to access does not belong to your business"
}
```
</ResponseExample>

## Errors

| Status | Typical cause |
|------|-------------|
| `400` | Insufficient funds, provider rejection, or the reference is already processing |
| `401` | Missing or invalid API key |
| `403` | Source or destination wallet belongs to another merchant |
| `404` | Source or destination account not found |
| `409` | Transaction reference has already been used |
| `422` | Missing field, non-positive amount, or invalid narration |

<Tip>
  Confirm that both account numbers belong to customers under your business before initiating the free internal transfer. If a successful request is retried with its original reference, FossaPay returns the existing successful result without moving funds again.
</Tip>
