---
title: 'Get Wallet by Account Number'
openapi: 'GET /api/v1/wallets/fiat/account/{accountNumber}'
description: 'Retrieve one of your business’s NGN wallets by account number'
---

## Path Parameters

<ParamField path="accountNumber" type="string" required>
  The account number of a master or customer wallet belonging to your business
</ParamField>

## Request

<ParamField header="x-api-key" type="string" required>
  API Key for authentication
</ParamField>

## Request Example

```bash
curl https://api-production.fossapay.com/api/v1/wallets/fiat/account/1234567890 \
  -H "x-api-key: $FOSSAPAY_API_KEY"
```

```javascript
const response = await fetch('https://api-production.fossapay.com/api/v1/wallets/fiat/account/1234567890', {
  headers: {
    'x-api-key': process.env.FOSSAPAY_API_KEY
  }
});

const data = await response.json();
const wallet = data.data;
```

```python
import os
import requests

url = "https://api-production.fossapay.com/api/v1/wallets/fiat/account/1234567890"
headers = {"x-api-key": os.environ["FOSSAPAY_API_KEY"]}

response = requests.get(url, headers=headers)
data = response.json()
wallet = data["data"]
```

## Errors

| Status | Typical cause |
|------|-------------|
| `403 Forbidden` | The wallet exists but does not belong to the authenticated business |
| `404 Not Found` | Wallet with this account number does not exist |
| `401` | Missing or invalid API key |
