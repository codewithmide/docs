---
title: 'Create Wallet'
openapi: 'POST /api/v1/wallets/fiat/create'
description: 'Provision the single NGN wallet allowed for a merchant-owned customer'
---

## Request

<ParamField header="x-api-key" type="string" required>
  Active production API key belonging to the customer's merchant.
</ParamField>

<ParamField body="customerId" type="string" required>
  FossaPay customer UUID. The customer must belong to the authenticated merchant.
</ParamField>

<ParamField body="walletName" type="string" required>
  Non-empty provider wallet and account display name.
</ParamField>

<ParamField body="walletReference" type="string" required>
  Non-empty correlation reference generated and stored by your system.
</ParamField>

### Request Example

```bash
curl -X POST https://api-production.fossapay.com/api/v1/wallets/fiat/create \
  -H "x-api-key: $FOSSAPAY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "customerId": "11111111-1111-4111-8111-111111111111",
    "walletName": "John Doe",
    "walletReference": "wallet-customer-1042"
  }'
```

```javascript
const response = await fetch('https://api-production.fossapay.com/api/v1/wallets/fiat/create', {
  method: 'POST',
  headers: {
    'x-api-key': process.env.FOSSAPAY_API_KEY,
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    customerId: '11111111-1111-4111-8111-111111111111',
    walletName: 'John Doe',
    walletReference: 'wallet-customer-1042'
  })
});

const data = await response.json();
const wallet = data.data;
```

```python
import os
import requests

url = "https://api-production.fossapay.com/api/v1/wallets/fiat/create"
headers = {
    "x-api-key": os.environ["FOSSAPAY_API_KEY"],
    "Content-Type": "application/json"
}
data = {
    "customerId": "11111111-1111-4111-8111-111111111111",
    "walletName": "John Doe",
    "walletReference": "wallet-customer-1042"
}

response = requests.post(url, headers=headers, json=data)
data = response.json()
wallet = data["data"]
```

## Response

<ResponseField name="status" type="string">
  `success` for a successful request.
</ResponseField>

<ResponseField name="statusCode" type="number">
  HTTP status code. Successful creation returns `201`.
</ResponseField>

<ResponseField name="message" type="string">
  Human-readable response message
</ResponseField>

<ResponseField name="data" type="object">
  <Expandable title="properties">
    <ResponseField name="walletId" type="string">
      Unique identifier for the wallet
    </ResponseField>

    <ResponseField name="bankName" type="string">
      Name of the bank
    </ResponseField>

    <ResponseField name="bankCode" type="string">
      Bank code
    </ResponseField>

    <ResponseField name="accountName" type="string">
      Account display name supplied through `walletName`.
    </ResponseField>

    <ResponseField name="accountNumber" type="string">
      Wallet account number
    </ResponseField>
  </Expandable>
</ResponseField>

## Errors

| Status | Typical cause |
|---|---|
| `400` | Customer not found, existing wallet, missing provider reference, or wallet provider failure |
| `401` | Missing or invalid API key |
| `422` | Invalid customer UUID or missing request field |
| `5xx` | Temporary platform or provider failure; reconcile before retrying |

<Tip>
  Store the wallet ID, assigned account details, and your wallet reference. Wallet creation does not provide idempotency semantics.
</Tip>
