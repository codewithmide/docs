---
title: 'Calculate Crypto Transfer Fee'
openapi: '/api-reference/openapi.json GET /api/v1/transfers/crypto/calculate-fee'
description: 'Calculate a Solana or Stellar crypto transfer fee'
---

## Request

<ParamField header="x-api-key" type="string" required>
  Active production API key.
</ParamField>

## Query Parameters

<ParamField query="amount" type="number" required>
  The transfer amount for which to calculate the fee. Must be a positive number (minimum `0.01`).
</ParamField>

<ParamField query="currency" type="string" required>
  The asset to calculate fees for: `sol`, `usdc`, `usdt`, or `xlm` (case-insensitive). Solana supports SOL/USDC/USDT; Stellar supports XLM/USDC.
</ParamField>

<ParamField query="network" type="string">
  `solana` or `stellar`. Specify `network=stellar` for Stellar USDC. If omitted, XLM selects Stellar and other assets select Solana.
</ParamField>

### Request Example

```bash
curl -g 'https://api-production.fossapay.com/api/v1/transfers/crypto/calculate-fee?amount=200&currency=usdc' \
  -H "x-api-key: $FOSSAPAY_API_KEY"
```

```javascript
const params = new URLSearchParams({
  amount: '200',
  currency: 'usdc',
});
const response = await fetch(
  `https://api-production.fossapay.com/api/v1/transfers/crypto/calculate-fee?${params}`,
  {
    method: 'GET',
    headers: {
      'x-api-key': process.env.FOSSAPAY_API_KEY,
    },
  }
);

if (!response.ok) {
  throw new Error(`Request failed: ${response.status} ${response.statusText}`);
}

const feeData = await response.json();
```

<Note>
  This endpoint uses **GET** with **query parameters**, not a JSON body. When using `curl` in a shell, wrap the full URL in quotes (or use `curl -g`) so `&` between query parameters is not treated as a background operator.
</Note>

## Response

<ResponseExample>
```json Success Response
{
  "status": true,
  "statusCode": 200,
  "message": "Transfer fee calculated successfully",
  "data": {
    "amount": 200,
    "currency": "usdc",
    "network": "solana",
    "feeAmount": 1,
    "total": 201
  }
}
```
</ResponseExample>

| Field | Description |
| ----- | ----------- |
| `data.amount` | The amount you passed in the query |
| `data.currency` | The quoted crypto asset |
| `data.network` | The network selected for the fee quote |
| `data.feeAmount` | The fee charged for the crypto payout |
| `data.total` | `amount` + `feeAmount`, provided as the fee-quote total |

<Note>
  In the current crypto transfer flow, the submitted transfer `amount` is gross and the fee is deducted before the recipient transfer. Use the quote to calculate the expected net recipient amount; do not interpret `data.total` as the amount debited by that transfer flow.
</Note>

## Validation errors

| HTTP status | Typical cause |
| ----------- | ------------- |
| `422` | Missing or invalid query params (for example, `amount` not positive or unsupported `currency`/`network`) |
| `400` | `amount` or `currency` missing after validation, or unsupported currency at the service layer |
| `401` | Missing or invalid API key |
