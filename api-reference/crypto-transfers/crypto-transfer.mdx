## Request

<ParamField header="x-api-key" type="string" required>
  Active production API key belonging to the customer and source wallet merchant.
</ParamField>

<ParamField body="customerId" type="string" required>
  UUID of the customer making the transfer
</ParamField>

<ParamField body="recipient" type="string" required>
  Complete recipient address on the selected network. Stellar requires a valid Stellar public address.
</ParamField>

<ParamField body="network" type="string" required>
  The blockchain network for the transfer: `solana` or `stellar`.
</ParamField>

<ParamField body="currency" type="string" required>
  Solana supports `sol`, `usdc`, and `usdt`. Stellar supports `xlm` and `usdc`. Use lowercase values.
</ParamField>

<ParamField body="amount" type="number" required>
  Gross token amount. The configured fee is deducted and the net amount is sent to the recipient.
</ParamField>

<ParamField body="memo" type="string">
  Optional Stellar text memo, maximum 28 characters. FossaPay generates a memo when omitted. This field is used only for Stellar transfers.
</ParamField>

### Request Example

```bash
curl -X POST https://api-production.fossapay.com/api/v1/transfers/crypto \
  -H "x-api-key: $FOSSAPAY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "customerId": "11111111-1111-4111-8111-111111111111",
    "recipient": "7EcJ1eB6J3ggRrGkQWsT4ZP8dkqPZ4JmW4YRwR7Qp5cY",
    "network": "solana",
    "currency": "usdc",
    "amount": 100.50
  }'
```

```javascript
const response = await fetch('https://api-production.fossapay.com/api/v1/transfers/crypto', {
  method: 'POST',
  headers: {
    'x-api-key': process.env.FOSSAPAY_API_KEY,
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    customerId: '11111111-1111-4111-8111-111111111111',
    recipient: '7EcJ1eB6J3ggRrGkQWsT4ZP8dkqPZ4JmW4YRwR7Qp5cY',
    network: 'solana',
    currency: 'usdc',
    amount: 100.50
  })
});

if (!response.ok) {
  throw new Error(`Request failed: ${response.status} ${response.statusText}`);
}

const transfer = await response.json();
```

For a Stellar transfer, set `network` to `stellar`, `currency` to `xlm` or `usdc`, and `recipient` to the destination's full Stellar public address. Add a `memo` if the recipient requires one:

```json
{
  "customerId": "11111111-1111-4111-8111-111111111111",
  "recipient": "GAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAWHF",
  "network": "stellar",
  "currency": "xlm",
  "amount": 5,
  "memo": "ORDER-123"
}
```

The address above is illustrative. Use the recipient's actual address and required memo when submitting a payment.

</ResponseExample>

<ResponseExample>
```json Error Response (400)
{
  "status": "error",
  "statusCode": 400,
  "message": "Crypto transfer failed. Try again later!"
}
```
</ResponseExample>

<ResponseExample>
```json Error Response (500)
{
  "status": "error",
  "statusCode": 500,
  "message": "Internal server error"
}
```
</ResponseExample>

The response indicates provider processing, not final blockchain settlement. This endpoint has no merchant-provided idempotency key or reference. After a timeout, inspect wallet history and balances before submitting another transfer. Stellar wallets must retain the configured native XLM reserve and enough XLM for network fees; the default reserve is 1.5 XLM.

## Errors

| Status | Typical cause |
|---|---|
| `400` | Customer/wallet unavailable, insufficient funds, unsupported operation, or provider rejection |
| `401` | Missing or invalid API key |
| `422` | Invalid customer UUID, currency, amount, memo, or network other than `solana` or `stellar` |
| `5xx` | Temporary platform or provider failure; reconcile before retrying |
