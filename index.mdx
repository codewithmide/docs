## Make your first request

Create the customer before provisioning their wallet. The returned customer ID connects the rest of the payment flow.

```bash Create a customer
curl -X POST https://api-production.fossapay.com/api/v1/customers \
  -H "x-api-key: fk_production_xxxxxxxx" \
  -H "Content-Type: application/json" \
  -d '{
    "firstName": "Amara",
    "lastName": "Okafor",
    "emailAddress": "amara@example.com",
    "mobileNumber": "+2348012345678"
  }'
```

## A clear path to your first payment

<Steps>
  <Step title="Authenticate securely">
    Create a production key in the dashboard and send it in the `x-api-key` header.
  </Step>
  <Step title="Create the customer and wallet">
    Create the customer first, then use the returned customer ID to provision their individual wallet.
  </Step>
  <Step title="Configure webhooks">
    Add your webhook URL and secret before initiating a payment so your application can verify every event.
  </Step>
  <Step title="Validate with a small live amount">
    Make a controlled production payment, verify the webhook, and retrieve the transaction record.
  </Step>
</Steps>
