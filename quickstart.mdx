## Get Started with FossaPay

This quickstart guide will have you making your first API call in minutes. We'll create a customer, open an NGN wallet, use production-only credentials, and verify a real deposit webhook.

## Prerequisites

Before you begin, make sure you have:
- A FossaPay account ([Sign up here](https://dashboard.fossapay.com/register))
- Your API keys from the [dashboard](https://dashboard.fossapay.com/settings?tab=api-keys)
- Node.js installed (or your preferred programming language)

## Step 1: Get Your API Keys

<Steps>
  <Step title="Sign up">
    Create an account at [dashboard.fossapay.com](https://dashboard.fossapay.com/register)
  </Step>
  <Step title="Get Live Keys">
    Navigate to **Settings** → **API Keys** and copy your production secret key (starts with `fk_production_`)
  </Step>
  <Step title="Store Securely">
    Save your API key as an environment variable:
    ```bash
    export FOSSAPAY_SECRET_KEY="fk_production_DTKUG..."
    ```
  </Step>
</Steps>

<Warning>
  FossaPay currently operates in production only. Any API call you make will hit production systems, so use small live amounts when you are validating your integration.
</Warning>

## Step 2: Create a Customer

Create the customer before creating any wallet or payment flow.

```bash
curl -X POST https://api-production.fossapay.com/api/v1/customers \
  -H "x-api-key: $FOSSAPAY_SECRET_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "firstName": "John",
    "lastName": "Doe",
    "middleName": "Michael",
    "emailAddress": "john.doe@example.com",
    "mobileNumber": "+2348012345678",
    "dateOfBirth": "1990-08-15",
    "address": "123 Main Street",
    "city": "Lagos",
    "country": "Nigeria",
    "type": "individual"
  }'
```

**Expected Response:**
```json
{
  "status": "success",
  "statusCode": 201,
  "message": "Customer created successfully",
  "data": {
    "id": "cus_123456789",
    "firstName": "John",
    "lastName": "Doe",
    "emailAddress": "john.doe@example.com",
    "mobileNumber": "+2348012345678",
    "customerType": "individual"
  }
}
```

<Success>
  **You created your first customer!** We'll use the returned customer ID in the next step.
</Success>

## Step 3: Create Your First NGN Wallet

Create an NGN wallet for the customer you just created:

```bash
curl -X POST https://api-production.fossapay.com/api/v1/wallets/fiat/create \
  -H "x-api-key: $FOSSAPAY_SECRET_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "customerId": "cus_123456789",
    "walletName": "Main Wallet",
    "walletReference": "wallet_ref_001"
  }'
```

**Expected Response:**
```json
{
  "success": true,
  "message": "NGN wallet created successfully",
  "data": {
    "walletId": "wal_abc123xyz",
    "bankName": "Wema Bank",
    "bankCode": "035",
    "accountNumber": "1234567890"
  }
}
```

<Success>
  **You created your first NGN wallet!** Share the returned account number with the customer so they can make a small live deposit.
</Success>

## Step 4: Configure Your Webhook

Configure your webhook URL and secret in the dashboard before making a live deposit.

1. Go to [Settings → Webhooks](https://dashboard.fossapay.com/settings?tab=webhooks)
2. Set your webhook URL
3. Copy the webhook secret and store it as `FOSSAPAY_WEBHOOK_SECRET`
4. Make sure your handler expects `deposit.completed` for incoming deposits

When a deposit is received in production, FossaPay sends a webhook to your server. Here's how to handle it:

<CodeGroup>

```javascript Express.js
const express = require('express');
const crypto = require('crypto');
const app = express();

app.use(express.json());

app.post('/webhooks/fossapay', (req, res) => {
  // 1. Verify webhook signature
  const signature = req.headers['x-fossapay-signature'];
  const isValid = verifySignature(req.body.data, signature);

  if (!isValid) {
    return res.status(401).send('Invalid signature');
  }

  // 2. Respond immediately
  res.status(200).send('Webhook received');

  // 3. Process the webhook
  const { eventType, data } = req.body;

  if (eventType === 'deposit.completed') {
    console.log('Deposit completed!');
    console.log('Amount:', data.amount);
    console.log('Transaction ID:', data.transactionId);

    // Credit user wallet, update database, send notification, etc.
    creditUserWallet(data.customerId, data.amount);
  }
});

function verifySignature(data, signature) {
  const secret = process.env.FOSSAPAY_WEBHOOK_SECRET;
  const hash = crypto
    .createHmac('sha256', secret)
    .update(JSON.stringify(data))
    .digest('hex');

  return hash === signature;
}

app.listen(3000, () => {
  console.log('Webhook server running on port 3000');
});
```

```python Flask
from flask import Flask, request
import hmac
import hashlib
import json
import os

app = Flask(__name__)

@app.route('/webhooks/fossapay', methods=['POST'])
def handle_webhook():
    # 1. Verify signature
    signature = request.headers.get('X-FossaPay-Signature')
    payload = request.json
    is_valid = verify_signature(payload['data'], signature)

    if not is_valid:
        return 'Invalid signature', 401

    # 2. Respond immediately
    # 3. Process webhook
    event = payload['eventType']
    data = payload['data']

    if event == 'deposit.completed':
        print('Deposit completed!')
        print(f'Amount: {data["amount"]}')
        print(f'Transaction ID: {data["transactionId"]}')

        # Credit user wallet, update database, etc.
        credit_user_wallet(data['customerId'], data['amount'])

    return 'Webhook received', 200

def verify_signature(data, signature):
    secret = os.environ['FOSSAPAY_WEBHOOK_SECRET']
    serialized_data = json.dumps(data, separators=(',', ':'), ensure_ascii=False)
    hash = hmac.new(
        secret.encode(),
        serialized_data.encode('utf-8'),
        hashlib.sha256
    ).hexdigest()

    return hmac.compare_digest(hash, signature)

if __name__ == '__main__':
    app.run(port=3000)
```

</CodeGroup>

## Step 5: Make a Small Live Deposit

From a bank account you control, send a small live deposit to the wallet account number from Step 3.

You should receive a `deposit.completed` webhook with the transaction details and customer ID.

## Step 6: Verify the Deposit

Use the transaction ID from the webhook to fetch the transaction record:

```bash
curl https://api-production.fossapay.com/api/v1/wallets/fiat/transactions/txn_abc123 \
  -H "x-api-key: $FOSSAPAY_SECRET_KEY"
```

## Step 7: Send a Small Production Payout

Now send a small amount directly from your business master NGN wallet to a bank account you control. Generate and retain one idempotency key for this logical payout:

```bash
curl -X POST https://api-production.fossapay.com/api/v1/payouts \
  -H "x-api-key: $FOSSAPAY_SECRET_KEY" \
  -H "X-Idempotency-Key: payout-quickstart-001" \
  -H "Content-Type: application/json" \
  -d '{
    "destinationBankCode": "044",
    "destinationAccountName": "Test Recipient",
    "destinationAccountNumber": "0000000001",
    "destinationBankName": "ACCESS BANK",
    "reference": "QUICKSTART-PAYOUT-001",
    "remarks": "Test payout",
    "amount": 100,
    "currency": "NGN"
  }'
```

An HTTP `202` response may contain `data.status: "processing"`. Wait for `payout.completed`, `payout.failed`, or `payout.reversed`, or retrieve the payout by ID/reference. Do not repeat an uncertain payout using a new idempotency key.

## Complete Example

Here's a complete example that ties everything together:

```javascript
const express = require('express');
const app = express();

app.use(express.json());

// Handle incoming deposits
app.post('/webhooks/fossapay', async (req, res) => {
  res.status(200).send('OK');

  const { eventType, data } = req.body;

  if (eventType === 'deposit.completed') {
    // Credit user's balance
    await creditUserBalance(data.customerId, data.amount);

    // Send notification
    await sendNotification(data.customerId, {
      title: 'Payment Received',
      message: `Your account was credited with ₦${data.amount}`
    });
  }
});

app.listen(3000);
```
